# closet
A simple WoW: Classic and WoW: Forever addon to track net gold income per session

Usage:

* `/midas` - Display your net income in the current session

Notes:

Midas keeps track of the starting and ending gold for each character every session. Eventually I'm considering adding more features like the ability to see net income over time (e.g. last day, week, month, year etc) and the addon is currently saving the data necessary to implement those features later.
